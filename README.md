JENIESYS MONTHSARY — MULTI-PAGE LOVE EXPERIENCE ♡

This version is intentionally split into separate pages. It is not one long scrolling page.

PAGES
- index.html   Home / opening
- memories.html Photo gallery
- quest.html   Five-question interactive love game
- video.html   Video surprise (unlocks after the quest)
- letter.html  Secret note and gift-box love letter

FILES TO ADD
Keep all HTML pages, style.css, and app.js together in the same folder.
Create an images folder and add your three photos using these exact names:
  images/photo1.jpg
  images/photo2.jpg
  images/photo3.jpg
Add your video beside the HTML files and name it:
  our-video.mp4

HOW TO USE
1. Extract the ZIP while keeping the folder structure intact.
2. Add your photos and video using the paths above.
3. Open index.html in a browser.
4. Use the top navigation to move between separate pages.
5. Complete the Love Quest to unlock the video and gift letter.

NOTES
- Designed for mobile and desktop with a shared, consistent layout.
- Gallery supports arrows, dots, and touch swiping.
- Quest progress is stored in localStorage in the same browser.
- It works offline; no external libraries or internet connection are required.
- For best video compatibility, use an MP4 encoded with H.264 video and AAC audio.
- Local browser storage may not be shared between different browsers or when switching to a hosted site.# moonth
