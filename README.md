BACKGROUND MUSIC (IMPORTANT)
══════════════════════════════════════════════════════════════
The site is ready to play:
  “Sheryl Cruz – Ikaw Ang True Love Ko”

Because of copyright you must add the audio file yourself:

1. Download a legal / personal copy of the song
   (YouTube Audio Library, your purchased track, etc.)
2. Convert it to MP3 if needed
3. Place the file in the same folder as index.html
4. Name it exactly:   music.mp3

The music starts after the first click (or when she taps
“Open your surprise”). There is a ♪ music button in the
top navigation on every page so she can pause/play it.

══════════════════════════════════════════════════════════════
HOW TO USE LOCALLY
══════════════════════════════════════════════════════════════
1. Keep the whole folder structure intact.
2. Make sure music.mp3 is present (see above).
3. Open index.html in a browser
   (or use a simple local server:  npx serve .)
4. Complete the Love Quest to unlock the video page and the gift letter.
5. Progress is saved in the browser’s localStorage.

══════════════════════════════════════════════════════════════
PUTTING IT ON GITHUB + GITHUB PAGES
══════════════════════════════════════════════════════════════
1. Create a new repository on GitHub (public or private).
2. Upload / push this entire folder (all HTML, CSS, JS, images/,
   our-video.mp4, and music.mp3).
3. Go to Settings → Pages
4. Source: Deploy from a branch → main → / (root)
5. Save. After a minute your site will be live at:
   https://YOUR-USERNAME.github.io/REPO-NAME/

Tip: If the video or music doesn’t play on mobile, make sure
the files are not too large and that the repo is public
(or the visitor is logged in if private).
